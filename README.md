# Numan Irshad | Portfolio

A modern portfolio website for Full-Stack Software Engineer Numan Irshad, built with Vite, React, TypeScript, and Tailwind CSS. The project highlights his technical experience, SaaS work, featured projects, and contact information for clients and collaborators.

## Overview

This portfolio showcases:

- Full-stack development expertise in Next.js, React, Node.js, and MongoDB
- Production SaaS projects built for international clients
- UI/UX-focused design and responsive front-end experiences
- Integration work with Stripe, Saferpay, Firebase, and automation tools
- A professional digital presence for personal branding and client acquisition

## Tech Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Router
- TanStack Query
- React Hook Form
- Zod
- Lucide React

## Features

- Responsive portfolio layout optimized for desktop and mobile
- Professional about, skill, and project sections
- Featured project cards with live links and technology tags
- Hero section with professional branding and resume CTA
- Contact and social media integrations
- Clean dark-themed design with modern UI styling

## Project Structure

```bash
numanirshad.dev/
├── public/                  # Static assets and downloadable resume files
├── src/
│   ├── components/         # Reusable UI sections and page blocks
│   ├── config/             # Personal profile and configuration data
│   ├── lib/                # Helper utilities and shared logic
│   ├── App.tsx             # App entry and page composition
│   ├── main.tsx            # React bootstrap file
│   └── index.css           # Global styles and theme variables
├── package.json            # Scripts and dependencies
├── vite.config.ts          # Vite configuration
├── tailwind.config.ts      # Tailwind configuration
├── tsconfig.json           # TypeScript configuration
├── eslint.config.js        # Linting configuration
└── README.md               # Project documentation
```

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Lint the codebase

```bash
npm run lint
```
